# 🛸 Protótipo do Projeto Aliens

Bem-vindo(a)! Este documento contém as informações e o link de acesso ao protótipo da nossa interface.

## 🛠️ Sobre a Produção

- **Fase Inicial (Google Stitchi):** O protótipo foi idealizado e estruturado inicialmente utilizando o **Google Stitchi**.
- **Migração para o Figma:** O projeto foi posteriormente exportado para o **Figma**. Essa transição foi necessária para garantir maior controle sobre a interface, pois a inteligência artificial da ferramenta anterior realizava alterações automáticas não solicitadas no layout. No Figma, conseguimos refinar o design, a estrutura e a interatividade com total precisão.

Nesta etapa, foram explorados o conceito visual, a estrutura das telas, e disposição dos elementos, servindo como referência para o desenvolvimento da aplicação.
